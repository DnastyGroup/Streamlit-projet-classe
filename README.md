# Streamlit-projet-classe
Premier depot github streamlit
## Installation requirements
Installation Python 3.7 ou supérieur in your laptop

1. Install python

* Go to official  website : https://www.python.org/downloads/
* Choose version 3.7 or supérieur
* Download and install it

2. Install Streamlit: 
  * run the following command in your terminal
  ```
    pip install streamlit

    or (verifier si c'est installé : streamlit hello)

    pip3 install streamlit
    ```
